- Issue: SIGINT can bypass publication repair, destroy the previous backup, or leave initialization committed after reporting interruption. Severity: high. Evidence: `StateStore._commit_pair()` and `_publish_bytes()` catch `Exception` only (`src/ovcaq/state/store.py:321,357`), while `KeyboardInterrupt` derives from `BaseException`. Reproduction at `BACKUP_REPLACED` returned `{"state_unchanged": True, "backup_unchanged": False, "backup_now_equals_state": True}`. Reproduction at initialization’s `STATE_REPLACED` left a readable revision-zero state after `initialize()` raised. Existing injected failures use an `Exception` subclass and therefore miss this path (`tests/state/test_store_transactions.py:654-742`, `tests/state/test_store.py:788-825`). Violated requirement: PRD success metric “Failed mutations leave state and backup byte-identical,” create-only initialization, crash-safe state writer, and Phase B failure-boundary testing.
