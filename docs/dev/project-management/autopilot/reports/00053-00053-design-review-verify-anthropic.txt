3. **non-blocker (already recorded) - Absent vs empty PATH (Interfaces & contracts, `claude.py:probe`).**
   - **Evidence:** "follows subprocess/default PATH semantics" is ambiguous.
     - `shutil.which(path=None)` falls back to `os.confstr("CS_PATH")`, while subprocess uses `os.get_exec_path(env)`, which falls back to `os.defpath`.
     - An empty `PATH` makes `shutil.which` return None. Subprocess would instead search the current directory.
     - The design's "stays empty" therefore means conservative-unhealthy, not parity with spawn.
   - **Fix:** compute `effective_path = os.pathsep.join(os.get_exec_path(env))`. Add a test that pins the empty-PATH expectation as deliberately conservative.
